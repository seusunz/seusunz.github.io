本文定位：标准解读 × 硬件视角。环路滤波处在编解码的重建环路里，滤波结果会作为后续帧的参考，所以编码端和解码端必须做完全一致的处理。本文按处理顺序介绍 VVC 的五个工具，代码位置以 VTM 9.3 为准。

0. 全景：重建图像的处理顺序

工具 解决的问题 处理粒度 相对 HEVC
LMCS 亮度码字分配不合理（HDR 尤其明显） 样点级映射，色度按块缩放 新增
DBF 去块滤波 块边界的不连续（方块效应） 4×4 / 8×8 网格上的边界 新增长滤波器，网格更细
SAO 块内部的振铃与亮度偏差 CTB 级参数，样点级补偿 基本沿用
ALF 整体重建误差 4×4 块分类，CTB 级开关 新增
CCALF 色度细节损失 与色度 ALF 并行 新增

从功能上看，前三者“修补特定类型的失真”，ALF 则用维纳滤波“最小化整体均方误差”，是 VVC 编码增益最大的环路工具之一。

1. LMCS：亮度映射与色度缩放

1.1 为什么要映射

视频的亮度分布往往很不均匀：SDR 内容的有效亮度通常只占 10 bit 码值范围的一部分；HDR PQ 内容在暗部和亮部对误差的敏感度差异很大。LMCS（Luma Mapping with Chroma Scaling）在编码环路内部把亮度重新映射，给更重要的亮度段分配更多码字，再对色度残差做相应的缩放补偿。

1.2 亮度：16 段分段线性映射

输入范围按位深等分为 16 段，每段宽度为 OrgCW = (1 << BitDepth) / 16（10 bit 时为 64）。码流（LMCS APS）中给出每段在映射域中占用的码字数 SignalledCW[i]，于是：

前向映射的段边界是等宽的，查段只需取高 4 位；反向映射的段边界 MappedPivot 不等宽，需要比较才能找到所在段。

1.3 映射发生在哪里

LMCS 的特殊之处在于，它让编码环路里同时存在原始域和映射域两个域：

环节 所在的域
帧内预测、残差、重建 映射域
帧间预测 参考帧在原始域，运动补偿后做一次前向映射，再与映射域残差相加
去块、SAO、ALF，以及存入参考帧缓存 原始域（重建后先做反向映射）

这样设计的好处是参考帧和环路滤波都留在原始域，只有“预测 + 残差”这一小段在映射域中进行。

1.4 色度残差缩放（CRS）

亮度被映射后，色度残差的量化误差分布也随之改变，所以 VVC 按亮度所在的映射段对色度残差做缩放。缩放因子由当前 64×64 单元上方和左侧相邻的重建亮度均值决定，而不是用同位置的亮度：用同位置亮度就得等亮度块重建完成，色度才能开始处理，会引入额外延迟。只有面积大于 4 的色度块才做缩放。

1.5 相关语法

层级 语法元素 含义
SPS sps_lmcs_enabled_flag 序列是否允许 LMCS
PH ph_lmcs_enabled_flag、ph_lmcs_aps_id、ph_chroma_residual_scale_flag 图像级开关、所用 APS、是否做色度缩放
SH sh_lmcs_used_flag Slice 级开关
APS lmcs_min_bin_idx、lmcs_delta_max_bin_idx 参与映射的段范围
APS lmcs_delta_abs_cw[i]、lmcs_delta_sign_cw_flag[i] 每段码字数相对 OrgCW 的增量
APS lmcs_delta_abs_crs、lmcs_delta_sign_crs_flag 色度缩放的微调量

2. 去块滤波（DBF）

2.1 方块效应从哪来

块划分编码中，相邻块的预测方式、量化误差各不相同，边界两侧的重建像素会出现不连续。平坦区域里，这种不连续表现为明显的“方块”。去块滤波沿块边界修正两侧样点，但必须避免把真实的图像边缘也平滑掉，所以它的核心是一套“要不要滤、滤多强”的决策。

2.2 哪些边界要处理

边界类型 网格
CU 边界、变换块边界（含 ISP、SBT 子块，以及超过 64 的大块隐式划分） 亮度 4×4 网格
预测子块边界（SbTMVP、仿射） 8×8 网格
色度边界 8×8 网格（以色度样点计）

处理顺序是先垂直边界、后水平边界：水平边界的滤波以垂直边界滤波后的结果为输入。

2.3 边界强度 Bs

每段边界先确定一个边界强度 Bs（LoopFilter.cpp:714 起）：

Bs 条件（按优先级）
2 任一侧是帧内块（两侧都是 BDPCM 时除外）；或者是变换块边界且任一侧使用 CIIP
1 变换块边界，且任一侧有非零系数（色度还包括联合色度残差编码）
1 任一侧使用 CIIP
1 两侧参考帧不同或 MV 个数不同；或对应 MV 的水平/垂直分量相差 ≥ 1/2 像素（nThreshold = 8，单位 1/16 像素）
0 其余情况，不滤波

亮度在 Bs > 0 时进入后续决策；色度的 Bs 只由帧内与系数条件决定，不检查 MV。

HEVC 中 MV 差的阈值是 1 个整像素，VVC 改为 1/2 像素，以配合更高的 MV 精度。

2.4 滤波开关与强弱决策

阈值 β 和 tC 由边界两侧的平均 QP（加上 Slice 级偏移）查表得到（LoopFilter.cpp:66-75），Bs = 2 时 tC 的查表索引额外加 2。VVC 还支持按亮度水平调整 QP 的 LADF，让暗区和亮区使用不同的滤波强度。

对每段 4 行（或 4 列）的边界，只取第 0 行和第 3 行做决策：

$$d = \sum_{k\in\{0,3\}} \Big( |p_{2,k} - 2p_{1,k} + p_{0,k}| + |q_{2,k} - 2q_{1,k} + q_{0,k}| \Big)$$

d 衡量的是边界两侧的平坦程度：d < β 才滤波，否则认为这里是真实的纹理或边缘。然后按以下条件选择滤波器：

滤波器 条件（概要） 修改范围
长滤波器 该侧块尺寸（垂直于边界方向）≥ 32，且两侧都足够平坦 该侧最多 7 个样点
强滤波器 两侧都很平坦，且边界跳变小于 2.5 tC 每侧 3 个样点
弱滤波器 其余情况 每侧 1~2 个样点

每侧的最大滤波长度由块尺寸预先确定（LoopFilter.cpp:491-535）：任一侧尺寸不超过 4 时只改 1 个样点；一侧尺寸达到 32 时，该侧可用长滤波器（最多 7 个）；其余为 3 个。两侧的长度可以不同，例如大块与小块相邻时，只在大块一侧做长滤波。

2.5 三种亮度滤波器

弱滤波器沿用 HEVC：

$$\Delta = \big(9\,(q_0 - p_0) - 3\,(q_1 - p_1) + 8\big) \gg 4$$

若 |Δ| < 10 tC，则把 Δ 限幅到 [−tC, tC]，令 p0′ = p0 + Δ、q0′ = q0 − Δ；当某一侧足够平坦时，再以更小的幅度修正 p1 或 q1。|Δ| ≥ 10 tC 说明这里很可能是真实边缘，不做修改。

强滤波器用 5 抽头低通重新计算两侧 3 个样点，例如：

$$p_0' = \big(p_2 + 2p_1 + 2p_0 + 2q_0 + q_1 + 4\big) \gg 3$$

长滤波器是 VVC 新增的。它在边界两侧之间做双线性插值：先求出两侧的“中值” Middle 和各自远端的参考值 P_s、Q_s，再按位置加权：

$$p_i' = \mathrm{Clip3}\big(p_i - tc_i,\ p_i + tc_i,\ (f_i \cdot \text{Middle} + (64 - f_i)\cdot P_s + 32) \gg 6\big)$$

权重 f_i 随离边界的距离递减。所有滤波结果都会被限幅在原值附近的 tC 相关范围内，防止过度平滑。

2.6 色度滤波

色度只有两种滤波器：两侧色度块都不小于 8 时可用强滤波（每侧改 3 个），否则用弱滤波（每侧改 1 个）。

2.7 CTU 边界上的特殊规则

在 CTU 的水平边界上，上方 CTU 一侧（P 侧）不使用长滤波器（LoopFilter.cpp:1045-1048），最多只修改 3 行。这条规则的目的是减少行缓存：解码到下一 CTU 行时，只需保留上一 CTU 行底部的少数几行像素，而不是 8 行。

3. SAO：样点自适应补偿

3.1 振铃从哪来

变换系数量化会丢失高频分量，重建图像在强边缘附近会出现类似吉布斯现象的波纹，即振铃效应。去块滤波只处理块边界，对块内部的振铃无能为力。SAO（Sample Adaptive Offset）的思路很直接：按规则把像素分类，再给每一类加一个由编码端统计得到、写入码流的补偿值，从统计意义上抵消重建误差。SAO 在 HEVC 中引入，VVC 基本沿用。

每个 CTB 可选三种模式：关闭、边缘补偿（EO）、边带补偿（BO）。

3.2 边缘补偿（EO）

先选 4 个方向之一，把当前像素 c 与该方向上的两个邻点 a、b 比较：

类别 条件 含义 补偿符号
1 c < a 且 c < b 局部谷点 正（抬高）
2 c < a 且 c = b，或 c = a 且 c < b 凹形边缘 正
3 c > a 且 c = b，或 c = a 且 c > b 凸形边缘 负（压低）
4 c > a 且 c > b 局部峰点 负
0 其他 平坦区域 不补偿

补偿值的符号由类别隐含，码流中只传幅度。这本身就是一种约束：EO 只会把峰削低、把谷填高，起到平滑作用。

3.3 边带补偿（BO）

把像素值范围均匀分成 32 个带（取像素值的高 5 位），码流中指定连续 4 个带的起始位置及各自的补偿值，落在这 4 个带内的像素加上对应补偿。BO 适合处理平坦区域中某一亮度段的整体偏差。

3.4 参数传输

补偿幅度上限为 (1 << (Min(bitDepth, 10) − 5)) − 1，8 bit 时为 7、10 bit 时为 31。当前 CTB 可以直接复用左侧或上方 CTB 的全部 SAO 参数（sao_merge_left_flag / sao_merge_up_flag），以节省码率。

4. ALF：自适应环路滤波

4.1 维纳滤波：最小化均方误差

ALF 的出发点是维纳滤波：找一组滤波系数，使滤波后的重建图像与原始图像的均方误差最小。设原始像素为 s(x)，滤波器的第 i 个输入为 r_i(x)，系数为 c_i：

$$E = \sum_{x} \Big( s(x) - \sum_{i} c_i\, r_i(x) \Big)^2$$

对每个 c_j 求偏导并令其为零，得到线性方程组：

$$\sum_i c_i \underbrace{\sum_x r_i(x)\,r_j(x)}_{R_{ij}} = \underbrace{\sum_x s(x)\,r_j(x)}_{p_j} \quad\Longleftrightarrow\quad \mathbf{R}\,\mathbf{c} = \mathbf{p}$$

R 是输入的自相关矩阵，p 是输入与原始像素的互相关向量。R 对称正定，可以用 Cholesky 分解求解，VTM 中对应 gnsSolveByChol。由于原始图像只有编码器知道，系数必须由编码器求出并写入码流，这也是 ALF 的滤波器尺寸不能太大的原因。

4.2 滤波器形状

分量 形状 独立系数 说明
亮度 7×7 菱形 13 中心对称的两个位置共用一个系数
色度 5×5 菱形 7 同上

系数精度为 7 bit（所有系数之和为 128），非中心系数的取值范围为 [−128, 127]，中心系数不传输，由归一化条件推出。

4.3 非线性 clipping

VVC 的 ALF 不是纯线性滤波。每个邻点先与中心像素做差，再按 clipping 门限截断，然后才参与加权：

$$\tilde{I}(x) = I(x) + \Big(\sum_{i} c_i \cdot \mathrm{Clip3}\big(-k_i,\ k_i,\ I(x+\Delta_i) - I(x)\big) + 64\Big) \gg 7$$

clipping 的作用是限制与中心差异过大的邻点的影响：真实边缘两侧的像素差很大，被截断后就不会把边缘抹平。每个系数位置可以从 4 个门限中选一个，门限只取决于位深（AdaptiveLoopFilter.cpp:745-756）：

clipIdx 0 1 2 3
门限 2^BitDepth 2^(BitDepth − 3) 2^(BitDepth − 5) 2^(BitDepth − 7)
10 bit 时 1024 128 32 8

clipIdx = 0 时门限等于整个取值范围，相当于不截断。

4.4 亮度 4×4 块分类

一帧里不同区域的纹理差异很大，一组系数难以兼顾。ALF 对亮度按 4×4 块分类，每类使用自己的滤波器。

1. 计算梯度：在 4×4 块周围的 8×8 窗口内隔点取 32 个位置，计算水平、垂直和两个对角方向的一维拉普拉斯值，并分别累加：

$$\begin{aligned} V_{k,l} &= |2R(k,l) - R(k,l-1) - R(k,l+1)|, &\quad H_{k,l} &= |2R(k,l) - R(k-1,l) - R(k+1,l)|\\ D0_{k,l} &= |2R(k,l) - R(k-1,l-1) - R(k+1,l+1)|, &\quad D1_{k,l} &= |2R(k,l) - R(k-1,l+1) - R(k+1,l-1)| \end{aligned}$$

2. 方向性 D（0~4）：比较水平/垂直梯度之比与两个对角梯度之比。两者都小于阈值 2 时为无明显方向的纹理（D = 0）；否则取比值较大的一组作为主方向，再按比值是否超过 4.5 区分弱方向（D = 1 或 3）和强方向（D = 2 或 4）。

3. 活动性 A（0~4）：水平与垂直梯度之和经量化得到，量化表见 AdaptiveLoopFilter.cpp:865。

4. 类别：

$$C = 5D + \hat{A},\qquad C \in [0, 24]$$

此外，按梯度的大小关系，对滤波器系数做 4 种几何变换之一（不变、对角翻转、垂直翻转、旋转）。这样方向相反或相互转置的纹理可以共用一组系数，相当于在不增加码率的前提下扩充了滤波器种类。

4.5 参数传输与 CTB 级控制

层级 内容
ALF APS 最多 8 个（ALF_CTB_MAX_NUM_APS）；每个可含最多 25 组亮度滤波器（类别间可合并）和最多 8 组备选色度滤波器
固定滤波器 16 组预定义的亮度滤波器集合，编解码器内置，不需要传输
CTB 级 每个 CTB 用开关标志决定是否做 ALF；亮度从“16 组固定 + 所用 APS”中选一组，色度选一组备选滤波器

4.6 CCALF：跨分量 ALF

色度在下采样和量化中丢失的细节，往往在亮度中还保留着。CCALF（Cross-Component ALF）用一个作用于亮度的小滤波器生成修正量，加到色度 ALF 的输出上：

要素 说明
输入 SAO 之后、亮度 ALF 之前的亮度样点，与中心亮度做差（相当于提取高频分量）
形状 3×4 菱形，最多 8 个位置（MAX_NUM_CC_ALF_CHROMA_COEFF，CommonDef.h:191）
滤波器数 每个色度分量最多 4 组（MAX_NUM_CC_ALF_FILTERS），CTB 级选择
输出 与色度 ALF 并行计算，结果相加

4.7 虚拟边界

ALF 滤波上下各需 3 行邻点，分类窗口还要更多。如果 CTU 底部的 ALF 要等下一 CTU 行的去块和 SAO 全部完成，行缓存会非常大。VVC 在 CTU 底部向上的固定位置设置虚拟边界（CommonDef.h:365-366）：

分量 虚拟边界位置
亮度 CTU 底部向上 4 行
色度 CTU 底部向上 2 行

跨越虚拟边界的邻点不读真实像素，而是做对称填充。于是当前 CTU 行的 ALF 不必等下一行的全部结果，代价是边界附近的滤波形状被“截断”，带来轻微的编码效率损失。

5. 硬件实现视角

5.1 环路滤波流水的错位与行缓存

五个工具之间是严格的生产者-消费者关系，而且每一级都需要上一级输出的邻域：

级 需要的邻域 对流水的影响
去块 边界两侧最多各 8 个样点；水平边界依赖垂直边界的结果 当前 CTU 的右侧和下方边界要等相邻 CTU
SAO 3×3 邻域（EO） 必须在去块之后，再向右下错开
ALF 7×7 菱形 + 分类窗口 必须在 SAO 之后，再错开若干行列

所以环路滤波各级处理的区域相对 CTU 网格逐级向左上偏移，每一级都要缓存上一 CTU 行底部和左侧 CTU 右边的若干行列。标准中的几条规则都在压缩这些缓存：

规则 节省的行缓存
CTU 水平边界上，去块的 P 侧不用长滤波器 上一 CTU 行只需保留 3 行左右，而不是 8 行
ALF 虚拟边界 ALF 不必等待下一 CTU 行
CCALF 与色度 ALF 并行 不额外增加一级流水

5.2 去块滤波的并行度

去块的决策以 4 行或 4 列为一段，各段之间没有依赖。同一方向上相邻的两条边界，VVC 通过“小块一侧只改 1 个样点、8 以上改 3 个、长滤波只用于 32 以上的块”这组规则，保证它们的修改范围不会重叠。硬件因此可以在一个 CTU 内并行处理多段边界，吞吐主要受“先垂直、后水平”这一依赖和边界决策逻辑的延迟限制。

5.3 ALF 滤波通路

分量 每像素主要运算
亮度 24 次差值、24 次 clip、12 次对称合并、12 次乘法、加法树
色度 12 次差值、12 次 clip、6 次乘法、加法树

由于中心对称的两个邻点共享系数，可以先把两侧 clip 后的差值相加再乘，乘法次数减半，这与帧间插值利用系数对称性是同一思路。乘法之后的加法树是滤波通路的关键路径，加法树的拓扑与流水切分位置对时序影响很大。

5.4 编码端：统计比滤波更贵

解码端只需滤波；编码端还要按 4.1 节求出系数。第一步是对每个类别累加自相关矩阵（亮度 13×13）与互相关向量，而且要为每种 clipping 取值分别统计。这一步在每个像素上都有大量乘累加，是编码端 ALF 硬件的面积与功耗大户；解方程本身运算量不大，但控制复杂、精度要求高。

编码端 ALF 在硬件上的完整取舍，包括类别裁剪、帧级推导的周期预算、行缓存数量的推导、双核协同等，见 ALF 项目复盘。

6. 小结

  1. 五个工具各管一类失真：LMCS 优化码字分配，去块处理块边界，SAO 处理振铃与偏差，ALF 最小化整体误差，CCALF 用亮度修正色度；
  2. “不滤真实边缘”是共同的设计约束：去块用 d < β 与 10 tC 判别，SAO 的 EO 只削峰填谷，ALF 用 clipping 限制大差值邻点；
  3. 很多规则是为行缓存而设：去块在 CTU 边界上限制长滤波，ALF 设虚拟边界，LMCS 的色度缩放使用相邻亮度而非同位亮度，都是在缩短流水依赖。
